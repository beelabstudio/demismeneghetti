A Especificação The Specification

login.spec.md 
# Feature: User Login Validation

## Rules
- Email: required, valid format (RFC 5322)
- Password: required, min 8 chars
- Max attempts: 5 (then 15-min lockout)
- Session: expires in 24h

## Edge Cases
- SQL injection attempts → rejected
- Empty fields → inline errors shown
- Remember Me → 30-day token
- Unicode passwords → accepted

"Este é o contrato." "This is the contract."

Escolha UMA Funcionalidade Pequena Choose ONE Small Feature
